# WeWrite Public Demo - Writing Preference Rules

This public playbook is a sanitized default. It contains reusable writing rules only and does not include any real account identity, user draft history, staff names, or private publishing records.

## Core Rule: Do Not Invent

- Do not fabricate student stories, quotations, authority statements, dates, locations, or numeric details.
- If source materials do not support a detail, use a general description.
- Keep campus and institutional writing warm but restrained.

## Structure

- Do not create a standalone "Lead Story" block in the body. Put introductory text into the first section intro.
- Keep section titles short. Let the section intro carry context.
- Put explanatory text before or after a group of images, not between every image.

## Style

- Prefer clear, concrete verbs.
- Remove empty slogans and over-literary emotion.
- Keep paragraphs concise enough for WeChat mobile reading.
- Avoid repeated phrases in the same article.

## Images

- Use captions only when they add context.
- Do not infer details from images unless the user provided those details.
- If imported photos are used, keep body text close to the activity facts.

## Signature

- Use the account's configured signature fields when present.
- For public demos, use placeholders such as "Editor: Demo".
